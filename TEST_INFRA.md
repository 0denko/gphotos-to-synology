## 1. Opaque-Box Testing Philosophy & Constraints

All tests in `tests/e2e/` are **requirement-driven opaque-box tests** designed directly against the `v1.2.0` public specification in `PROJECT.md` and `Collab.md`:

1. **Public Entry Points Only**:
   - **HTTP API**: FastAPI `create_app()` exercised via `fastapi.testclient.TestClient` and live loopback `uvicorn` HTTP servers (`start_live_fastapi_server`).
   - **DSM CGI Gateway**: `synology-spk/ui/proxy.cgi` and `synology-spk/ui/oauth_callback.cgi` executed as real `/usr/bin/python3` subprocesses (`run_cgi`) speaking the CGI environment/stdin/stdout wire protocol against local HTTP servers.
   - **SPK Packaging & POSIX Lifecycle Scripts**: `synology-spk/build_spk.py` invoked via CLI subprocess (`build_test_spk`), unpacked (`extract_spk`), and its embedded `scripts/start-stop-status`, `scripts/preupgrade`, and `scripts/preuninst` executed via strict POSIX `/bin/sh` (`dash`) (`run_posix_script`).
   - **Frontend JavaScript (`app.js` & `GPhotosMigrator.js`)**: Verified via `node --check` syntax validation and executed inside an isolated Node `vm` browser DOM/fetch harness (`run_app_js_scenario`) that faithfully models browser `div.textContent` / `div.innerHTML` quote behavior.
   - **Public Python Subsystem APIs**: `Settings`, `ConfigManager`, `StateDB`, `ProfileRegistry`, `MigrationPipeline`, `BackgroundScheduler`, `Notifier`, `UpdateService`, `LocalInboxScanner`, `GoogleDriveClient`, `ExistingLibraryScanner`, `SynologyFolderImporter`, `SynologyPhotosClient`, `extract_archive`, `cleanup_stale_temp_files`, `DirectoryJsonIndex`, `find_sidecar_json`, `parse_sidecar_json`, `apply_metadata`, `compute_media_fingerprint`, `is_perceptual_match`, and `compare_image_quality`.
2. **Zero Host Leakage**:
   - An `autouse=True` fixture (`_isolate_e2e_env`) clears all `GPHOTOS_*`, `SYNOLOGY_*`, `GOOGLE_*`, `API_TOKEN`, `PROXY_SECRET*`, `WATCHTOWER_*`, and path environment variables before every test, and `make_isolated_settings(tmp_path)` passes `_env_file=None` so local `.env` files never pollute test runs.
3. **Deterministic Local Network & Media Fixtures**:
   - Zero external internet access is performed. Synology DSM `/webapi/entry.cgi`, webhook receivers, CGI upstreams, and GitHub Releases endpoints are served by deterministic local `ThreadingHTTPServer` or `httpx.MockTransport` fixtures.
   - Synthetic JPEGs (with textured geometric patterns, controllable Gaussian blur, and custom/corrupt EXIF APP1 segments), PNGs, real HEIC images (via `pillow-heif`), and Takeout `.zip` / `.tar.gz` archives are generated on the fly in `tmp_path`.

## 5. Opaque-Box Fixtures & Helpers (`tests/e2e/conftest.py`)

`tests/e2e/conftest.py` provides the following reusable fixtures and builders:

- **Environment & Settings Isolation**:
  - `_isolate_e2e_env` (`autouse=True` fixture): Strips all application-relevant environment variables before each test.
  - `make_isolated_settings(base_dir, **overrides) -> Settings`: Builds an isolated `Settings(_env_file=None, ...)` rooted under `tmp_path` and creates required directories.
  - `make_csrf_headers()`, `make_proxy_headers(...)`, `make_token_headers(...)`: Build request header dictionaries matching `PROJECT.md § Interface Contracts #1`.
- **Synthetic Media & Takeout Archive Builders**:
  - `make_patterned_image(width, height, *, seed, blur_radius)`: Generates deterministic geometric RGB images with distinct dHashes per `seed` and controllable Laplacian sharpness.
  - `image_to_jpeg_bytes(...)`, `save_jpeg(...)`, `save_png(...)`: Render synthetic JPEG/PNG files to bytes or disk.
  - `save_heic(path, width, height, *, seed, quality)`: Generates genuine HEIC files via `pillow_heif`.
  - `make_corrupt_exif_jpeg_bytes(...)` / `save_corrupt_exif_jpeg(...)`: Builds a valid JPEG with a malformed APP1 EXIF segment that causes `piexif.load` to raise (for G13 verification).
  - `make_sidecar_payload(title, *, timestamp, description, lat, lon, alt)`: Builds Google Takeout sidecar JSON dicts.
  - `build_zip_archive(dest_path, entries)` & `build_tar_gz_archive(dest_path, entries, *, symlinks)`: Construct Takeout `.zip` and `.tar.gz` archives.
  - `make_stub_exiftool(tmp_path)`: Creates an executable POSIX `#!/bin/sh` stub `exiftool` that logs invocations.
- **Local HTTP Servers & Live Loopback FastAPI Server**:
  - `mock_dsm_server` (`MockDSMServer` / `MockDSMState`): Ephemeral `ThreadingHTTPServer` implementing Synology `/webapi/entry.cgi` (`SYNO.API.Auth`, `SYNO.Foto.Browse.Album`, `SYNO.Foto.Browse.NormalAlbum`, `SYNO.Foto.Browse.Folder`, `SYNO.Foto.Browse.Item`, folder tree resolution, code `119` session expiry simulation, and request method/query/form recording).
  - `mock_webhook_server` (`MockWebhookServer`): Ephemeral `ThreadingHTTPServer` recording webhook/Watchtower requests with configurable latency (`delay_seconds`) and HTTP status code (`status_code`).
  - `mock_backend_server` (`MockBackendServer`): Ephemeral `ThreadingHTTPServer` for isolated CGI subprocess tests, supporting custom status codes, response headers, and raw HTTP wire bytes (for CRLF injection testing).
  - `start_live_fastapi_server(settings)`: Context manager launching a real `uvicorn` server on `127.0.0.1:<ephemeral_port>` for end-to-end `proxy.cgi` / `oauth_callback.cgi` → FastAPI tests.
  - `make_github_mock_client(handler)`: Returns an `httpx.Client` with `httpx.MockTransport` for deterministic `UpdateService` tests.
- **Subprocess Runners (CGI, SPK Builder, POSIX `/bin/sh`, Node `vm`)**:
  - `run_cgi(script_path, *, backend_url, method, query_string, body, ...)`: Executes `proxy.cgi` or `oauth_callback.cgi` under `/usr/bin/python3` and parses CGI `Status:` / headers / body output.
  - `build_test_spk(...)`, `extract_spk(...)`, `parse_spk_info(...)`, `run_posix_script(...)`: Build `.spk` packages into `tmp_path`, unpack outer tar and inner `package.tgz`, parse `INFO`, and run lifecycle scripts under `/bin/sh` (`dash`).
  - `run_app_js_scenario(...)`: Executes `src/gphotos_synology/web/static/app.js` inside Node's `vm` module with a browser-faithful DOM/fetch harness and returns all recorded `fetchCalls` and inspected DOM element states.
